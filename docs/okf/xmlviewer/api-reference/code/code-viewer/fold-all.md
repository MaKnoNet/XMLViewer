## `public void foldAll()`


Keine Parameter. Ruft `callJs("foldAll")` auf (klappt alle faltbaren Blöcke im Editor zu — die
eigentliche Faltlogik liegt clientseitig in CodeMirror). `void`, keine Exceptions im
`CodeViewer`-Rumpf.
