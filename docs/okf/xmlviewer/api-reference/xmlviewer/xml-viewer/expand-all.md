## `public void expandAll()`


- Keine Parameter. Klappt alle Elemente auf, deren Kinder-Container im aktuellen Baum bekannt
  sind (`tree.childContainers().keySet()`).
- Rückgabewert: keiner.
- Exceptions: keine.
